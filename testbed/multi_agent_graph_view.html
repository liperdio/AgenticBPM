Procure-to-Pay Agent Graph

Compiled structure of the LangGraph state graph, exported directly from app.get_graph().draw_mermaid(). Intake runs unconditionally into Verification and Approval; Approval branches on its own decision, ending the process on approval, or handing off to Escalation Routing when escalated. 

graph TD;
	__start__([start]):::first
	intake(Intake Agent)
	verification(Verification Agent)
	approval(Approval Agent)
	escalation_routing(Escalation Routing Agent)
	__end__([end]):::last
	__start__ --> intake;
	intake --> verification;
	verification --> approval;
	approval -. approve .-> __end__;
	approval -. escalate .-> escalation_routing;
	escalation_routing --> __end__;
	classDef first fill:#CADCFC,stroke:#1E2761,color:#1E2761
	classDef last fill:#1E2761,stroke:#1E2761,color:#FFFFFF
Solid arrow unconditional handoff
Dashed arrow conditional edge, labeled with the decision that triggers it
